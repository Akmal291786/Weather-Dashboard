# Weather Dashboard

A simple Weather Dashboard built using C++.

## Features

- Search weather by city name
- Display temperature
- Display weather condition
- Display humidity
- Display wind speed
- Simple console-based dashboard

## Technologies Used

- C++
- Object-Oriented Programming
- File/Console I/O
- Git & GitHub
